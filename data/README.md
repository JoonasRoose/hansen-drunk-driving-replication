# Data Instructions

This replication uses a modified version of the Washington State DUI dataset associated with Hansen (2015), “Punishment and Deterrence: Evidence from Drunk Driving.”

The dataset is not included in this repository because it was provided for course use and may have distribution restrictions.

To run the code, place the provided CSV file in this folder with the exact filename:

modified_hansen_data.csv

The expected path is:

data/modified_hansen_data.csv
